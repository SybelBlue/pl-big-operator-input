pl-sum-notation-input QA

Each example exercises a different public configuration of the element. Enter the displayed sum or integral in the fields beneath it.

1. Defaults and inline correct answer

\[\displaystyle \sum_{i=1}^{6} i^2\]

2. Explicit sum mode, exact grading, server answer, and variables

\[\displaystyle \sum_{k=0}^{n} (a k+b)\]

3. Piecewise grading and custom component/element weights

\[\displaystyle \sum_{j=-m}^{m} (j+c)^3\]

4. Equivalent grading (explicit)

This configuration also accepts an equivalent affine reindexing.

\[\displaystyle \sum_{r=2}^{8} (r-1)\]

5. Integral mode with an inline correct answer

\[\displaystyle \int_0^2 x^3\,dx\]

6. Integral mode, exact grading, server answer, and variables

\[\displaystyle \int_a^b (t^2+c)\,dt\]

7. Integral mode with piecewise grading

\[\displaystyle \int_{-L}^{L} y^2\,dy\]

8. Greek index, trigonometric input, and answer precedence

The inline answer should take precedence over the deliberately different server answer.

\[\displaystyle \int_0^{\pi} \sin(\theta)\,d\theta\]
